📓 PART 1 — 단계 ① 04 / 14

NotebookLM이란?

내가 올린 자료만 학습하는 AI 리서치 파트너

🔒
소스 기반 AI
내가 업로드한 자료만 참고 — 엉뚱한 답 최소화
📎
출처 인용
답변이 어느 자료에서 나왔는지 바로 확인 가능
🎙️
오디오 오버뷰
자료를 팟캐스트 형태로 자동 요약 생성
💡 오늘 사용법
notebooklm.google.com → 새 노트북 생성 → 소스 추가 → 질문 → 📝 노트 저장
노트북 제목: "노포기록단 촬영 준비 자료"
📓 단계 ② 05 / 14

다큐 촬영법 자료 조사 & 저장

1
소스 추가
구글에서 "10분 단편 다큐 촬영법" 검색 → 유튜브 링크 또는 웹 URL을 NotebookLM에 추가
2
아래 프롬프트로 정리 요청
채팅창에 붙여넣기 → 답변을 📝 노트에 저장
📌 노트 저장 제목
"촬영 기법 정리"
📓 NotebookLM 프롬프트
10분 내외 단편 다큐를 스마트폰으로 촬영할 때 핵심 기법을 정리해줘. 1. 오프닝 씬을 임팩트 있게 시작하는 법 2. 공간(가게)을 자연스럽게 소개하는 순서 3. 인물을 따뜻하게 담는 앵글과 거리 4. 음식·손 클로즈업 촬영 팁 5. 감성적인 클로징 씬 만드는 법 6. 조명·소음·흔들림 대처법 현장에서 바로 쓸 수 있는 실용 팁으로.
📓 단계 ③④ 06 / 14

시나리오 작성법 + 인터뷰 기법

📓 단계 ③ — 시나리오 프롬프트
노포를 소재로 한 10~15분 다큐 시나리오 작성법을 알려줘. 1. 3막 구성 적용법 2. 첫 30초 오프닝 훅 만드는 법 3. 가게와 사람 이야기를 엮는 서사 방식 4. 씬 목록 작성 예시 (번호/장소/내용/시간) 5. 편집 순서 예시 스마트폰 촬영 기준으로.
📓 단계 ④ — 인터뷰 프롬프트
노포 사장님 인터뷰에서 감동적인 이야기를 이끌어내는 방법을 정리해줘. 1. 인터뷰 전 라포 형성 방법 2. 열린 질문 vs 닫힌 질문 활용법 3. 감동 유도 질문 패턴 6가지 4. 대화 끊겼을 때 이어가는 법 5. 인터뷰 흐름 (시작→핵심→마무리) + 예시 질문 8개 포함.
📌 노트 저장
③ "시나리오 작성법"  ④ "인터뷰 기법 & 예시 질문"
📓 단계 ⑤⑥ 07 / 14

촬영 스크립트 + AI 이미지 프롬프트

📓 단계 ⑤ — 촬영 스크립트
지금까지 저장한 자료를 종합해서 노포 다큐 촬영용 스크립트 양식을 만들어줘. 포함 항목: - 씬번호 / 장소 / 시간대 - 촬영 내용 + 카메라 앵글 - 내레이션 / 자막 텍스트 - 인터뷰 질문 (해당씬) - 체크박스 위 양식으로 샘플 스크립트도 작성.
📓 단계 ⑥ — AI 이미지 프롬프트
노포 다큐 콘텐츠에 어울리는 AI 이미지 프롬프트를 용도별 3개씩: 0. 스크립트에 맞춘 9분할 이미지 1개를 생성(기본) 1. 앱 배경 (따뜻한 노포 분위기) 2. 유튜브 썸네일 (빈티지·감성) 3. 음식 클로즈업 스타일 4. 사람 손·뒷모습 감성샷 5. 오래된 골목·간판 한국어 설명 + 영어 프롬프트 함께.

✨ 단계 ⑦ 09 / 14

자료 연결 & 앱 기능 설계

1
NotebookLM 노트를 제미나이에서 연결
저장된 노트 → 제미나이 대화창에서 연결하기
2
앱 기능 목록 먼저 제안 받기
바로 코드 요청 X → 먼저 기능 목록 논의 후 멤버들과 함께 조정
3
"OK" 사인 후 코드 생성
기능 확정 → 다음 슬라이드 프롬프트로 앱 생성 요청
✨ Gemini 프롬프트 — 앱 설계
위에 붙여넣은 자료들은 노포 다큐멘터리를 스마트폰으로 촬영하기 전에 준비하는 내용이야. 이 자료들로 촬영자가 현장에서 바로 쓸 수 있는 스마트폰 최적화 웹앱을 만들 거야. 먼저 앱 기능 목록을 제안해줘: - 탭 구성 (몇 개, 어떤 내용) - 각 탭의 핵심 기능 - 체크박스·입력 등 인터랙션 요소 제안 후 내가 OK하면 웹앱(HTML)형식으로 만들어줘.
✨ 단계 ⑧ 10 / 14

바이브 코딩으로 앱 완성

✨ Gemini — 앱 생성 프롬프트
좋아, 앱을 만들어줘. 요구사항: - 스마트폰 최적화 (max-width 480px) - 탭: 가게정보 / 씬구성 / 인터뷰질문 / 장비체크 / AI프롬프트카드 - 디자인: 따뜻한 갈색·앤틱 톤 - 체크박스 완료 시 취소선 + 전체 진행률 표시 - HTML 파일 하나로 완성 (CSS·JS 포함) 전체 HTML 코드를 출력해줘.
💬 바이브 코딩 수정 예시
→
"씬 추가 버튼도 넣어줘"
→
"인터뷰 질문을 카테고리별로 구분해줘"
→
"AI 프롬프트에 복사 버튼 추가해줘"
→
"색상을 더 빈티지하게 바꿔줘"
→
"다크모드 토글도 추가해줘"
💡 저장 방법
코드 복사 → .html로 저장 → 구글 드라이브 공유 링크 → QR로 스마트폰 접속
